## Agnes Hub v{{VERSION}}

基于已验证稳定的 **v1.0.11** 做体验优化（刻意不引入后期版本导致「思考中卡死」的空闲看门狗与请求体改写）：

- **控制台实时动态图表（运行实况 · 实时）**：每秒采样、自动滚动的「负载率 %」「处理规模（到达 / 完成 / 在途 / 排队）」「多账号分配堆叠面积图」，带 429 / 熔断事件刻度，无需手动刷新页面。
- **429 限流网关内自动重试**：限流专享 8 次重试预算，网关自动排队 + 换号重试，客户端几乎永远拿不到 429、任务不中断。
- **全局 RPM 系数**：「节流与排队」设置页新增「全局 RPM 系数」（默认 1.0），与按账号 RPM 覆盖独立叠加，作用于全部账号有效 RPM。
- **关闭服务端 keep-alive**：网关重启 / 热更后客户端不再复用上个进程残留的半死连接（另一类「思考中卡死」的成因）。
- **账号池优先级排序**：调度支持「按账号优先级排序安排调用」开关（设置页，默认开）。开启时优先级数字大的账号稳定顶到前面；关闭则退化为纯负载均衡（忽略账号优先级，同优先级内仍按区域 / 预计等待兜底）。原「站点优先级（401/403 自动换站）」设置已移除，区域偏好固定为国内优先。

### 适用场景
- 飞牛 fnOS：下载 `agnes-hub-go-{{VERSION}}.fpk`，应用中心安装 / 升级。
- Windows 绿色版：下载 `agnes-hub-go-windows-{{VERSION}}.zip`，解压后运行 `agnes-hub-go.bat` 启动。
